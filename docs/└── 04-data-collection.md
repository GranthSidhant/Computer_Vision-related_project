# Data Collection and I-Frame Extraction\n\n## 1. Purpose\n\nThe first step in creating the dataset is to collect useful images of wild animals.\n\nFor this project, animal videos are used as a source of images. Instead of manually taking screenshots from videos, **FFmpeg** is used to automatically extract I-frames from the videos.\n\nAn I-frame is a video frame that can be decoded independently and contains a complete image. Extracting I-frames provides a convenient way to obtain representative frames from a video without saving every single frame.\n\nThe extracted images will later be reviewed and selected for labeling in **Label Studio**.\n\n---\n\n## 2. Data Collection Workflow\n\nThe current workflow is:\n\n`text\nAnimal Videos\n      |\n      v\nFFmpeg\n      |\n      v\nExtract I-Frames\n      |\n      v\nReview / Select Images\n      |\n      v\nLabel Studio\n      |\n      v\nDraw Bounding Boxes\n      |\n      v\nExport Labeled Dataset\n      |\n      v\nYOLO Dataset\n`\n\nThis process is part of the dataset preparation stage of the project.\n\n---\n\n## 3. Software Used\n\n### FFmpeg\n\n**FFmpeg** is a command-line multimedia processing tool. It can read, process, and convert video and audio files.\n\nIn this project, FFmpeg is used to extract I-frames from animal videos.\n\n### Python\n\nPython is used to create a small automation script that runs FFmpeg and manages the input and output paths.\n\nThe Python script uses the built-in `subprocess` module to execute the FFmpeg command.\n\n---\n\n## 4. Installing FFmpeg\n\nOn Windows, FFmpeg can be installed using **Windows Package Manager (winget)**.\n\nOpen **Command Prompt** or **PowerShell** and run:\n\n`cmd\nwinget install -e --id Gyan.FFmpeg\n`\n\nAfter installation, FFmpeg should be available from the command line.\n\nTo verify the installation, run:\n\n`cmd\nffmpeg -version\n`\n\nIf FFmpeg is installed correctly, this command should display information about the installed FFmpeg version.\n\n---\n\n## 5. Python I-Frame Extraction Script\n\nThe following Python script uses FFmpeg to extract I-frames from a video.\n\n`python\nimport subprocess\nimport os\n\nvideo_path = r"d:\\1.mp4"\noutput_folder = r"d:\\iframes"\n\nos.makedirs(output_folder, exist_ok=True)\n\noutput_pattern = os.path.join(output_folder, "iframe_%04d.jpg")\n\ncommand = [\n    "ffmpeg",\n    "-i", video_path,\n    "-vf", "select=eq(pict_type\\\\,I)",\n    "-fps_mode", "vfr",\n    output_pattern\n]\n\nresult = subprocess.run(\n    command,\n    capture_output=True,\n    text=True\n)\n\nprint("Return code:", result.returncode)\n\nif result.returncode == 0:\n    print("I-frames extracted successfully.")\nelse:\n    print("FFmpeg error:")\n    print(result.stderr)\n`\n\nThe script will be stored in the repository as:\n\n`text\nsrc/data/extract_iframes.py\n`\n\n---\n\n## 6. How the Script Works\n\n### 6.1 Import required modules\n\n`python\nimport subprocess\nimport os\n`\n\n`os` is used for creating directories and constructing file paths.\n\n`subprocess` is used to execute the FFmpeg command from Python.\n\n---\n\n### 6.2 Specify the input video\n\n`python\nvideo_path = r"d:\\1.mp4"\n`\n\nThis specifies the location of the video that will be processed.\n\nThe `r` before the string creates a **raw string**, which makes Windows paths easier to write because backslashes do not need to be escaped in the usual way.\n\nThe current example expects the video to be located at:\n\n`text\nd:\\1.mp4\n`\n\nThis path should be changed when processing a different video.\n\n---\n\n### 6.3 Specify the output folder\n\n`python\noutput_folder = r"d:\\iframes"\n`\n\nThis specifies where the extracted I-frames will be saved.\n\n---\n\n### 6.4 Create the output directory\n\n`python\nos.makedirs(output_folder, exist_ok=True)\n`\n\nThis creates the output directory if it does not already exist.\n\n`exist_ok=True` prevents Python from producing an error if the directory already exists.\n\n---\n\n### 6.5 Define the output filename pattern\n\n`python\noutput_pattern = os.path.join(output_folder, "iframe_%04d.jpg")\n`\n\nThe `%04d` part creates sequential four-digit numbers for the extracted images.\n\nFor example:\n\n`text\niframe_0001.jpg\niframe_0002.jpg\niframe_0003.jpg\niframe_0004.jpg\n`\n\nThis makes the extracted frames easier to organize and process.\n\n---\n\n### 6.6 Build the FFmpeg command\n\nThe script creates the FFmpeg command as a Python list:\n\n`python\ncommand = [\n    "ffmpeg",\n    "-i", video_path,\n    "-vf", "select=eq(pict_type\\\\,I)",\n    "-fps_mode", "vfr",\n    output_pattern\n]\n`\n\nThe important part is:\n\n`text\nselect=eq(pict_type,I)\n`\n\nThis tells FFmpeg to select frames whose picture type is `I`, meaning **I-frames**.\n\nThe `-fps_mode vfr` option allows the output to use variable frame timing because I-frames do not necessarily occur at regular intervals.\n\n---\n\n## 7. Running FFmpeg from Python\n\nThe command is executed using:\n\n`python\nresult = subprocess.run(\n    command,\n    capture_output=True,\n    text=True\n)\n`\n\nThe script captures FFmpeg's output so that the result can be checked after the command finishes.\n\n---\n\n## 8. Checking for Errors\n\nThe script checks the return code:\n\n`python\nif result.returncode == 0:\n    print("I-frames extracted successfully.")\nelse:\n    print("FFmpeg error:")\n    print(result.stderr)\n`\n\nA return code of `0` indicates that the FFmpeg command completed successfully.\n\nIf an error occurs, the FFmpeg error message is printed so that the problem can be investigated.\n\n---\n\n## 9. Running the Script\n\nAfter FFmpeg has been installed and Python is available, run the script using Python.\n\nFor example:\n\n`cmd\npython src\\data\\extract_iframes.py\n`\n\nBefore running the script, make sure that the `video_path` points to the video that should be processed.\n\nFor example:\n\n`python\nvideo_path = r"d:\\1.mp4"\n`\n\nand that the output directory is appropriate:\n\n`python\noutput_folder = r"d:\\iframes"\n`\n\n---\n\n## 10. Output\n\nAfter successful execution, the output directory will contain the extracted I-frames.\n\nExample:\n\n`text\nd:\\iframes\\\n│\n├── iframe_0001.jpg\n├── iframe_0002.jpg\n├── iframe_0003.jpg\n├── iframe_0004.jpg\n└── ...\n`\n\nThese images can then be reviewed to determine which frames are useful for the dataset.\n\n---\n\n## 11. From Extracted Frames to Label Studio\n\nThe extracted images are not automatically considered training data.\n\nThey first need to be reviewed and labeled.\n\nThe next stage is:\n\n`text\nExtracted I-Frames\n        |\n        v\nReview Images\n        |\n        v\nSelect Useful Images\n        |\n        v\nUpload to Label Studio\n        |\n        v\nDraw Bounding Boxes\n        |\n        v\nAssign Animal Class\n        |\n        v\nExport Dataset\n`\n\nFor example, an image containing a tiger would receive a bounding box and the class label:\n\n`text\nTiger\n`\n\nThe same process will be followed for the other animal classes in the dataset.\n\n---\n\n## 12. Current Dataset Classes\n\nThe initial project focuses on visually similar wild cats:\n\n- Jaguar\n- Cheetah\n- Leopard\n- Tiger\n\nThe classes may be expanded or modified as the project develops.\n\n---\n\n## 13. Current Progress\n\nAt the time of writing:\n\n- Animal videos are being used as the source of training images.\n- FFmpeg is being used to extract I-frames.\n- A Python script has been created to automate the extraction process.\n- Label Studio has been installed for image annotation.\n- Approximately 50 images have already been labeled.\n\nThe dataset is still under development.\n\n---\n\n## 14. Important Note About I-Frames\n\nThe current script extracts **I-frames**, rather than every frame in the video.\n\nThis reduces the number of images that need to be reviewed and labeled. However, I-frames alone may not always provide enough variety for a machine learning dataset.\n\nLater in the project, different frame-selection strategies may be tested and compared if necessary.\n\nFor example, the project may investigate:\n\n- Extracting frames at fixed time intervals\n- Extracting more frames from important sections of a video\n- Removing duplicate or nearly identical images\n- Comparing I-frame extraction with regular frame sampling\n\nAny such changes will be documented as experiments rather than silently replacing the current method.\n\n---\n\n## 15.
