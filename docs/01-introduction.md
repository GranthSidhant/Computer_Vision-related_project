# Introduction

## Project

This project is about using **computer vision** to detect wild animals from images.

The project is being developed as part of my first semester of the **Master of Computer Applications (MCA)** program.

In simple terms, the goal is to teach a computer to look at an image and identify whether a wild animal is present and which animal it is.

## Initial Animal Classes

The project currently focuses on wild animals from the cat family, including:

- Jaguar
- Cheetah
- Leopard
- Tiger

These animals are being used because some of them can look visually similar, making them a useful challenge for an object detection model.

## Current Work

The project is currently at the **data preparation stage**.

The current work consists of:

1. Collecting animal videos.
2. Extracting frames from the videos using a Python script and FFmpeg.
3. Selecting the extracted frames.
4. Labeling the images using Label Studio.

At the moment, the main focus is on extracting frames and labeling the images.

The project will be documented step by step as the work progresses.
