# Wild Animal Detection

A beginner-level computer vision project developed as part of my first semester of the **Master of Computer Applications (MCA)** program.

The goal of this project is to train a model to detect wild animals from images and, eventually, use the detection to alert people.

## Current Focus

The project is currently in the **data preparation and image labeling stage**.
